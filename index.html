Firebase & Firestore Connection

This application is built with vanilla HTML/CSS/JS and supports both direct Cloud Firestore connection and the built-in local Firestore simulator for instantaneous testing on GitHub Pages.

Firestore Security Rules (`firestore.rules`): Included in project root. Enforces role-based checks (`request.auth.uid`), prevents direct client modification of check-in records, and protects token validity.
